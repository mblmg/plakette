=== Prüfstand – SEO & Ladezeit ===
Requires at least: 6.5
Tested up to: 7.1
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Prüft deine Website auf SEO-Mängel und misst die Ladezeit. Jeden Mangel kannst du mit einem Klick beheben – mit einer Erklärung für Einsteiger und jederzeit rückgängig.

== Beschreibung ==

* 34 Prüfungen: Sichtbarkeit, Permalinks, HTTPS, Sitemap, robots.txt, Titel, Meta-Beschreibungen, Open Graph, strukturierte Daten, Alternativtexte, H1, kaputte Links, Beispielinhalte, Seiten-Cache, Komprimierung, Browser-Cache, große Bilder, LCP-Bild, blockierende Skripte, Google Fonts (lokal), Emojis, jQuery Migrate, Dashicons, Datenbank, PHP-Version, Objekt-Cache.
* Prüft die echte Ausgabe deiner Seite (wie ein Besucher sie sieht) und misst Ladezeit-Kennzahlen im Browser.
* Jede Änderung steht im Protokoll und lässt sich rückgängig machen (Ausnahme: Datenbank-Aufräumen).
* Was nur der Hoster ändern kann, bekommt eine fertige Nachricht zum Kopieren.

== Installation ==

1. ZIP unter Plugins › Installieren › Plugin hochladen installieren und aktivieren.
2. Im Menü „Prüfstand“ öffnen und „Website jetzt prüfen“ klicken.

== Deaktivieren und Löschen ==

Beim Deaktivieren entfernt Prüfstand seinen Seiten-Cache (Drop-in und WP_CACHE). Beim Löschen werden Einstellungen, Protokoll, Sicherungen und die .htaccess-Regeln entfernt. Inhalte, die du verbessert hast (Alternativtexte, Titel, Beschreibungen), bleiben erhalten.
